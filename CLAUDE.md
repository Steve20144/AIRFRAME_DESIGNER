# Context management

Keep active context minimal.

Before reading files:
1. Search for relevant files first.
2. Read only the sections required for the current task.
3. Do not recursively inspect the whole repository unless necessary.
4. Use ./brain as persistent project memory.
5. When useful information should survive this session, summarize it into ./brain.
6. Prefer concise summaries over keeping old raw context active.
7. If context grows substantially, compact/summarize before continuing.

Target working set:
- CLAUDE.md
- current task
- relevant source files
- at most 3–5 relevant brain notes
