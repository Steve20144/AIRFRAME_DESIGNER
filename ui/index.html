Kill switch test

      

        
Proof that the emergency stop cuts every motor in any phase. In HITL the board's real outputs
          stay locked (SYS_HITL 1): it drives only the simulated aircraft. Start recording, arm, start the rotation with
          the takeoff switch, engage the kill switch; release it and wait 4 s. Repeat while holding and after the
          handover. Each kill is listed with the time until every motor output is off, the time until the outputs report
          disarmed, and whether anything came back after the release.
