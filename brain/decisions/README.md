# Decisions

This directory contains Architecture Decision Records (ADRs).

Create a new file for every significant decision.

Recommended filename format:

    YYYY-MM-DD-short-decision-name.md

Example:

    2026-09-21-use-local-stt.md

Template:

# Decision: Title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded

## Context

What problem are we solving?

## Decision

What did we decide?

## Reasoning

Why?

## Alternatives Considered

What alternatives were evaluated?

## Consequences

What changes because of this decision?\n
